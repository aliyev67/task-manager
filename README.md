# Task Manager

Консольный менеджер задач на Java 21: добавление задач с приоритетом, сортировка, отметка о выполнении и удаление. Бизнес-логика отделена от консольного интерфейса и покрыта unit-тестами на JUnit 5.

## Возможности

- Добавление задачи с названием и приоритетом (`LOW` / `MEDIUM` / `HIGH`)
- Список всех задач: сначала `HIGH`, затем `MEDIUM`, затем `LOW`; при равном приоритете — по номеру
- Список только невыполненных задач
- Отметка задачи как выполненной
- Удаление задачи
- Понятные сообщения об ошибках: пустое название, неизвестный приоритет, несуществующий номер, ввод не числа


## Технологии

- Java 21 (`record`, `enum`, Stream API, `switch` со стрелками)
- Maven
- JUnit 5

## Структура проекта

```
src/
├── main/java/com/islam/
│   ├── Main.java                   # консольное меню: ввод/вывод, обработка ошибок
│   ├── TaskService.java            # бизнес-логика: хранение и операции над задачами
│   ├── Task.java                   # record: id, title, priority, done
│   ├── Priority.java               # enum: LOW, MEDIUM, HIGH
│   └── TaskNotFoundException.java  # исключение для несуществующей задачи
└── test/java/com/islam/
    └── TaskServiceTest.java        # unit-тесты TaskService
```

## Архитектурные решения

- **Разделение слоёв.** `TaskService` ничего не знает о консоли, а `Main` не содержит бизнес-логики. Сервис можно переиспользовать, например, в REST API без изменений.
- **Неизменяемая модель.** `Task` — это `record`. Метод `complete()` не меняет задачу, а создаёт новую с `done = true` и заменяет её в хранилище.
- **Уникальные id.** Номера выдаются счётчиком и не переиспользуются после удаления, поэтому номер всегда указывает на одну и ту же задачу.
- **Исключения вместо кодов ошибок.** Сервис бросает `IllegalArgumentException` (некорректные данные) и `TaskNotFoundException` (задача не найдена); меню перехватывает их и показывает пользователю, программа продолжает работу.
- **Хранилище — `HashMap<Integer, Task>`.** Поиск, выполнение и удаление по номеру — за O(1).

## Как запустить

Требуется JDK 21 и Maven.

```
git clone https://github.com/aliyev67/task-manager.git
cd task-manager
mvn compile
java -cp target/classes com.islam.Main
```

Или открыть проект в IntelliJ IDEA и запустить `Main`.

## Тесты

```
mvn test
```

Покрыты все операции `TaskService`: добавление (включая пустое название и обрезку пробелов), сортировка, выполнение, удаление, фильтр невыполненных и ошибки для несуществующего номера.
